## Variantes

1. variante de exito

```js
toast.success({
  title: "Success",
  description: "This is a success message",
});
```

2. variante de error

```js
toast.error({
  title: "Error",
  description: "This is a error message",
});
```

3. variante de advertencia

```js
toast.warning({
  title: "Warning",
  description: "This is a warning message",
});
```

4. variante de información

```js
toast.info({
  title: "Info",
  description: "This is a info message",
});
```

## Opciones para variantes

| opcion      | tipo   | descripción                     |
| ----------- | ------ | ------------------------------- |
| title       | string | Título de la notificación.      |
| description | string | Descripción de la notificación. |
